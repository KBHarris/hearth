# Security Policy

Hearth is pre-release software and is not yet suitable for protecting sensitive
communications.

## Reporting a vulnerability

Please do **not** open public issues for security problems. Report them privately through
GitHub Security Advisories ("Report a vulnerability" on the repository's Security tab).

We aim to acknowledge reports within 3 business days. We coordinate disclosure with
reporters and credit them unless they ask us not to.

A full disclosure process and a bug bounty will be in place before 1.0 (see Phase 7 in
[docs/ROADMAP.md](docs/ROADMAP.md)).
